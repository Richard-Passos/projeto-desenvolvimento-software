<summary>
  <h2>👀 Sobre o Projeto</h2>
</summary>

<p>
  Projeto desenvolvido para a disciplina de Desenvolvimento de Software da UFRGS. O sistema transforma textos em sequências musicais, interpretando seus caracteres para gerar notas, pausas e mudanças nos parâmetros de execução.
</p>

<p>
  Desenvolvido em Python, com PyGame para a reprodução sonora, o projeto utiliza orientação a objetos e o padrão MVC para organizar suas responsabilidades e facilitar a evolução do código.
</p>

<summary>
  <h2>🎯 Objetivo</h2>
</summary>

<p>
  O foco do projeto é desenvolver um software organizado, testável e fácil de manter. A arquitetura deve permitir incorporar novas regras e funcionalidades conforme os requisitos evoluem, evitando alterações desnecessárias em partes já existentes.
</p>

<p>
  Para isso, buscamos aplicar boas práticas de programação, princípios SOLID e refatoração contínua ao longo do desenvolvimento.
</p>
